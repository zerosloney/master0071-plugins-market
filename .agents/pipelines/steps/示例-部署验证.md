# 步骤 — 部署验证（示例）

> kit steps 扩展点示例：把项目领域动作注册为可被编排脚本引用的步骤。文件名即步骤名；按项目实际改写。

1. 跑终端命令：`npm run deploy -- --env <env>`（工作目录 = 项目根）；非零即步骤失败，回报 stderr 尾段
2. 跑冒烟检查：`curl -fsS https://<env>.example.com/healthz`（URL 按项目改写）；非零即步骤失败
3. 回报：部署版本号（取 deploy 输出中的 version 行）+ 冒烟检查结果
