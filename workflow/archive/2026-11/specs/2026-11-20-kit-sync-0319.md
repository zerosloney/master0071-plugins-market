## 功能行为

**场景 A：台账历史基线三级声明（蓝本 4416666 判据级移植）**——check-ledger-invariant.mjs 基线解析从两级（env > 内置）扩为三级：`env LEDGER_HISTORY_BASELINE（测试覆盖口）> 仓库声明 .agents/notes/ledger-history-baseline.md（首个 LEDGER_HISTORY_BASELINE=<sha>，7-40 位 hex）> 内置基线`。首个有值者经 rev-parse 校验（不把任何来源哈希当硬事实）；文件缺失/读失败/无匹配即视为未声明（''）。行为细则：
- env 与声明/内置同值 → 不算覆盖口、不刷「测试用覆盖」告警；
- 覆盖值解析失败 → 回落 `REPO_BASELINE || BUILTIN`（消息指明回落来源），**不退全史**；
- 无任何有效基线 → loud WARN（含声明方式指引：文件路径 + 环境变量名）后 null = 全史扫描——fail-open 于深度、fail-closed 于内容口径不变；
- doctor.mjs 新增 advisory 检查项「台账历史基线声明」：判据同蓝本含 manifest 门——`readManifest 在场 && 有确认台账（.agents/confirmations.jsonl 或 .agents/confirmations.d/）且声明文件与 env 皆缺 → warn + 修复提示`；任一声明的即 ok。插件 doctor 现仅 ok 二态（doctor.mjs:97-104 聚合 every(c.ok)、渲染仅 ✓/✗），**须新增 warn 第三态**（纯增向后兼容：检查项加 warn 字段、聚合 warn 不计入 exit 码、渲染加 warn 形态三处），蓝本 advisory 语义即「warn 不硬红」。

**场景 B：policyVersion 落账（蓝本 66bf13a-① BACKLOG 33）**——confirm-doc.mjs 四台账写点（reconfirm / ai-auto-trust / 协作道 brief / tty 常规，当前树锚 448/687/735/759）随行落 `policyVersion`：确认时刻规范版本，单源 `loadKitPolicy`（confirm-doc.mjs:54 已 import），主流程开始处读一次（进程内只读一次）。纯增字段、历史行不回填。取值口径以**插件单源**为准（与蓝本在此已分叉）：engine.json 缺 policyVersion / 缺失 / 不可解析 → 落 1（policy.mjs:217 既有）；**不在版本表内 → loadKitPolicy throw**（policy.mjs:219-222，2026-11 市场审查裁决的 fail-closed，本单不触）——越界装户下 confirm-doc 主流程读一次会随之 throw，与 check-loop 等既有消费方同口径。

**场景 C：dirtyTree 脏树摘要（蓝本 66bf13a-② BACKLOG 34）**——新增单源 `scripts/git-tree-digest.mjs`（无副作用模块，判据逐字同蓝本）：`git status --porcelain` 失败 → null（调用方省键，不伪造）；空 → ''（干净树，不再问 diff）；否则 sha256(porcelain + '\n' + (`git diff HEAD` 成功则 stdout 否则 '')) 前 16 位 hex；零提交仓 diff 失败只以 porcelain 入摘要；diff spawn `maxBuffer: 32MB`。消费两处，红绿同口径：
- verify.mjs recordFailure 失败行（~368）与全绿行（~959）：`const dirtyTree = dirtyTreeDigest(ROOT); if (dirtyTree !== null) entry.dirtyTree = dirtyTree;`
- gen-verify-evidence.mjs renderRow：非空 string 摘要 → notes 列加「非干净树」；**列位以插件既有列序为准**——dirtyNote 插在 envNote 之后、headNote 之前（插件特有 headNote/srcNote 两 note 保留不动，:74-78；蓝本无此两项）；'' 与缺字段存量行渲染一字不变（未知 ≠ 脏）；摘要表头说明补「非干净树」口径段。

**场景 D：gitignore 标记块幂等（蓝本 053802e 判据级移植）**——install/apply.mjs applyGitignore：
- 块外去重：块体（BEGIN/END 标记间内容）落块前按文件**块外**行集去重（trim 比对）——装户块外已有条目不重复写进托管块；
- 块尾收敛：替换路径块体无尾换行，块后只剩换行（或空）时收敛为单 eol——EOF 空行不再逐次升级累积；旧版多空行产物在下次升级收敛，此后逐字节稳定；
- EOL 归一：块体按文件 EOL（eolOf 同款 CRLF 检出）归一；「无文件→新建 / 无块→追加」既有语义保持；
- plan.mjs `GITIGNORE_ENTRIES` 单源不动。

**场景 E：收口**——版本位 0.3.19（release --check 口径）；本仓首个装户声明 `.agents/notes/ledger-history-baseline.md` 落地（值=本仓台账全序恢复提交，owner 口径见关单）。
