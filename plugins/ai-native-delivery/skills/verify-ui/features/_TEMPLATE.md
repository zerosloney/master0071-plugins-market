# 特性：<顶层路由>

> 特性地图种子（本插件只发这一份模板）。**地图是项目数据，不是插件数据**——在你自己项目的
> `.agents/skills/verify-ui/features/<slug>.md` 里写，或用生成器落骨架：
>
> ```bash
> node <插件根>/skills/verify-ui/scripts/gen-verify-feature.mjs --route /your-route
> ```
>
> 生成器把骨架写进项目侧 `.agents/skills/verify-ui/features/`，从不写插件安装目录。
> 项目侧目录存在时，本目录只读参与覆盖统计，不会被当作你的地图。

四段缺一不建；填完再用于实测。

## 到达路径

hash 路由 `#/<路由>`。入口：<侧栏 / 列表 / 按钮>；到达后点哪个元素才算进到这一页。

## 驱动

用户 POV 的操作步骤；优先稳定锚点（ARIA / data-testid / 路由），不要依赖样式类或坐标。

## 可观察终态

什么现象证明它工作：可见文案、状态色、表格列、接口字段（给 `file:line` 或字段名）。
至少写一条「正常路径」和一条「失败/边界路径」（校验 / 空态 / 权限）。

## Gotchas

前置条件、坑、已知漂移。**账号、人名、工号这类项目侧数据不要写进来**——地图会随项目提交，
写进来等于把个人数据放进版本库。
