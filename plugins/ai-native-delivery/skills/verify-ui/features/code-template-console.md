- **按钮状态三态勿混判「改色未生效」**：默认态白底灰边黑字；hover/active 变 antd 主题蓝（`#4096ff`/`#0958d9`）。关抽屉后鼠标若仍悬在按钮上会保持 hover 蓝——这是状态不是样式遗漏。判定改色一律看 `getComputedStyle`（bg/color/class），勿从截图读色：JPEG 色噪 + 标注框会让灰边黑字按钮看起来发蓝（2026-10-26 用户截图即此误读，像素扫描证实其按钮为标准默认态）。
