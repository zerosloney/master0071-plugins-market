# 特性：汇率设置（扁平台账 + 导入/导出）

> 特性地图种子。事实锚点为建档时点代码，漂移时先修地图再出结论。

## 到达路径
侧边栏「基础数据 → 汇率设置」，或深链 `#/exchange-center?type=BASE&source=USD&target=CNY&status=1&from=2026-09-23&to=2026-10-23&page=1&pageSize=20`。2026-10-23 起为**单页扁平台账**（原「左币种对 / 右历史」主从结构已下线）。

## 驱动
筛选（汇率类型 / 源币种 / 目的币种 / 报价日期范围 / 状态）→ 列表（服务端分页）→ 行内「编辑 / 停用·启用 / 历史」。工具栏按钮顺序：**新增汇率 / 导入 / 导出Excel / 类型设置 / 币种设置**（无「生成反向」）。**新增/编辑汇率为弹窗**（720px）；**类型设置、币种设置**为页面内视图层（对齐供应商模块：覆盖列表区、面包屑 + 返回、不走路由），其内「新增/编辑」为普通弹窗。历史为行级抽屉。

## 可观察终态
- 列：币种对、汇率类型、报价日期、直接汇率、间接汇率、来源、状态、操作时间、操作。
- 状态三态：`生效中`（后端 `isCurrentActive`：该「类型+币种对」下 `status=1 且 quoteDate<=今天` 的最新一条）/ `有效` / `停用`；每对至多 1 条 `生效中`。
- 历史抽屉：该对全部报价（pageSize=1000），「较上期」相对同对上一报价日的涨跌幅，红涨绿跌；无前任显示 `—`。
- 导入：模板 7 列（汇率类型\* / 源币种\* / 目的币种\* / 报价日期\* / 直接汇率 / 间接汇率 / 备注）。**汇率类型填名称**（如「基准汇率」），按名称 trim + 忽略大小写匹配；填成编码会报「请填写名称「基准汇率」，不要填编码 BASE」。模板不含来源/状态：导入固定 `RateSource=2（导入）`、`Status=1（有效）`；界面新增汇率固定来源=手工。预览逐行校验（类型启用且维护主数据、币种存在且启用、源≠目的、日期、汇率 >0 且互为倒数、库内/文件内重复），执行整体事务。
- 导出：xlsx，列含状态（生效中/有效/停用），行数 = 当前筛选总数。

## Gotchas
- 类型/币种设置页无顶部说明条；唯一保留的提示是汇率类型弹窗「允许手工覆盖」label 的问号 tooltip（右侧弹出，文案「不维护主数据的类型必须允许手工覆盖（汇率在单据上手工录入）」）。
- 「生效中」以前端/后端本地「今天」为界；未来日期报价显示「有效」但不标「生效中」，也不参与订单取数。
- 列表 `isCurrentActive` 由 `ExchangeRateService.GetListAsync` 按页内（类型,源,目的）逐对查询标注（N ≤ pageSize 次小查询），非窗口函数。
- 类型 `requiresMasterData=false`（如 USER）时整页降级为引导空态，列表不渲染。
- 启停必须随发 `remark`：后端 `UpdateAsync` 对 `Remark` 无条件覆盖。
- 「生成反向」只预填 direct = 旧 indirect（单侧），另一侧留空由后端按目的币种精度算倒数；双侧同填会触发「不互为倒数」400。
- 导入模板示例行（第 2 行）是示例数据，导入前需删除；预览会把示例行当真实行校验。
- dev/test 库常见集成测试遗留类型（`PO引用测试类型`），类型下拉会照常展示；属数据污染，不是页面缺陷。
- 实测造数须按 POST 返回 ID 精确 DELETE 回滚并 SELECT 复核残留 0。
