## 到达路径
hash 路由 `#/pml`（定额PML 托盘列表）。主列表进入不取数，点「查询」或带参进入才取数（`useListQueryGate`）。

## 驱动
进入 `#/pml` → 观察未查询空态；填任意不存在的托盘号 → 点「查询」→ 观察查询后无结果空态。对照组：`#/mto-orders` 同两步。
详情/编辑/新增（2026-10-24 跃迁后）：点行内「托盘号」链接 → **覆盖层详情**（view 态）；行内「编辑」→ 覆盖层编辑态；工具栏「新增托盘」→ 覆盖层新增态。原 90% 屏宽抽屉已下线，无 a-drawer 残留。
行操作在 **hover 浮层**里（无固定操作列）；`/pml` 的被点行必须真身播种会话（资格判据是「创建人工号 === 登录工号」，
用 harness 缺省 `jobNo='Admin'` 会把所有行判成非本人 → 零动作行）。

## 可观察终态
- 查询栏为 `SearchPanel` 网格（`--search-cols: 6`）：6 个筛选（托盘号 / 项目号 / 专业 / 托盘类型 / PML状态 / PML提交）
  与「仅显示我创建的」复选框 + 查询/重置**同处一行**（7 列 = 6×`minmax(0,1fr)` + auto）；同列标签等宽、控件吃剩余宽度
  （2026-10-26 用户口径「参照采购订单」，替换原 flex + 140px 定宽；单行口径由
  `scripts/verify/e2e/pml-query-bar-single-row-check.mjs` 钉住，1920 / 2560 两档各 5 断言）。
- 工具栏：左组「新增托盘 / 导入托盘」，右组 3 个批量按钮（PML提交 / 取消提交 / 删除）靠右、竖线分隔；
  无选中全禁用，勾选后带「（N）」计数（2026-10-26 用户口径）。
- 行 hover 浮层**只渲染可用动作**（不可用即不渲染节点）：匹配MTO / 定额拷贝 / PML提交 / 编辑（均需本人 + 未提交，
  各自另叠 `detailCount` / `matchStatus` / `trayType` 条件）、取消提交（已提交 + 本人）、删除（未提交 + 无明细 + 本人）；
  一个动作都没有的行不浮出浮层。查看入口仍在「托盘号」链接（详情覆盖层）。
- **既有会弹框**的确认类入口（取消提交 / 删除 / 批量各项）弹出**单层居中 `Modal.confirm`**（无 `Popconfirm` 气泡）；
  「PML提交」**不弹框**（沿 spec 2026-10-13-pml-required-tip-and-submit-guard：入口已收窄为「仅全部匹配」，不再叠确认）。
- 列宽（2026-10-26 用户口径）：`关联PBS` 收窄为定宽 110px（多为单值，多值靠 hover 全文），
  弹性宽度交给 `托盘描述`（`flex: 1.5 / minWidth: 160`）；全表列头零截断。
- 空态与 `#/mto-orders` 需求单列表同形态：仅一行提示文字、无插画；文案由 `useListQueryGate()` 单源生成：
  未查询态「请设置查询条件后点击查询」；已查询无结果「暂无数据」。
- 覆盖层详情（2026-10-24，commit `9eff3bbd`）：`.pml-list > .detail-layer` 铺满列表区、无遮罩、返回即收起（对齐采购订单页）；
  上半区「基本信息/操作信息」页签 + 下半区「定额明细/匹配详情」页签，页签行右端=导出/明细工具条+最大化。

## Gotchas
- 不要为了套八模块空态规范（80px 插画 + `.list-empty`）给本页恢复 `#emptyText` 插槽——2026-10-22 曾如此改过，
  2026-10-23 用户要求与 MTO 需求单列表一致后回退。本页空态基准是 `/mto-orders`，不是插画规范。
- 改空态文案只改 `frontend/src/utils/listQueryGate.ts`（20+ 列表页共用），不要在单页硬编码字符串。
- 查询栏加筛选会挑战「单行」：加项前先按 `pml-query-bar-single-row-check.mjs` 复算占宽预算（1920 视口可用约 1780px）。
- 列表行级「匹配MTO」**不开覆盖层**：列表页独立挂 DlgMatchMTO 实例，会话装载走 `shared.ts mapPMLDetailToRows`
  （详情装载同源映射）；覆盖层内同名按钮走「先保存再匹配」。两入口勿混用装载路径。
- 「仅显示我创建的」复选框在 `#actions` 槽内、外层 `span.search-item-only-mine` 承载类名——
  `scripts/verify/e2e/list-entry-no-autoload-check.mjs` 靠它取 `input[type=checkbox]`，改结构要同步该门。
- 探针驱动本页表单控件须把表单查询**限定 `.pml-detail` 作用域**——列表搜索栏有同名 label/占位（项目号/托盘号），
  全局 query 会命中被覆盖层挡住的搜索栏控件（2026-10-24 实测踩坑：选择全落空）。
