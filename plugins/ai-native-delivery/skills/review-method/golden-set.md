# 独立复核黄金集（golden-set）

> 校准资产（2026-10-16 建集，调研建议4）：从已闭环 incident/papercut 提炼的带已知答案评审样本。
> 用途：①月度对账抽样比对独立复核结论与事后结果（mechanism-registry 登记）；②复核员/新会话自检——
> 对样本盲评后对答案，命中差 = 校准差。**每条样本带本仓上下文要点**（泛化样本无校准力，外部实证：
> 注入仓库上下文 96% vs 野外 56.3% 拒绝）。
> 纪律：样本引用的是闭环时事实；对应代码后续演进不改已知答案（答案锚定当时的 incident 定性）。

## 使用方法

1. **盲评（双臂）**：遮住「已知答案 / 上下文要点」两列，按本技能双轴框架独立给结论——报/不报 + 级别（P0/P1/P2）+ 根因方向一句话。
   - **A 臂（默认）**：复核员装载本技能（含本仓回归清单与红线口径）。
   - **B 臂（对照，月度抽 5–8 条即可）**：把同样的题面交给**干净会话**，只给样本内联的仓库上下文，不载本技能。
   - **Δ = A 命中差 − B 命中差**是唯一能证明「上下文注入起作用」的数；两臂同样准说明校准力来自样本内联而非技能文档，两臂同样差说明该样本的已知答案不可判——两种情形都记进留痕表的「臂」列，不互相冒充。
2. **对答案**：三档记——**命中**（动作与定性同向：应报且档位/根因同向，或应放行且未报）；**误报**（应放行却报）；**漏报**（应报未报，或报了但根因方向错）。
3. **方差复跑**：同会话对**可疑判定**（与已知答案不符，或与常识相悖的轻松命中）原样再评一次；判定翻转 → 归**评分方差**（题面或 rubric 有歧义），本轮不计入命中差，另开 papercut 修题面；判定不翻转才计**校准差**。目的：别让基础设施噪声冒充模型/复核方差。
4. **记录**：**首月留痕起于本表下方「月度盲评留痕」**（2026-10-17 前该资产已建成但零次跑数——登记册状态列「现役」指集已存在，不指已有数据）。按月汇总：月份 | 参评样本数 | 臂（A/B）| 命中/误报/漏报 | Δ | 方差复跑翻转次数 | 与 `workflow/reviews.d/` 当月片互参的备注。该片是复核事件级的「采纳/拒绝/误报」计数，本表是样本级命中差——两种粒度不混算，只在备注列关联。
5. **校准债**：命中差（误报+漏报 ÷ 参评样本数）连续两月 >20% → 在 `workflow/papercuts.d/` 当月片登记校准债，拟修指向角色契约 / 复核提示词条目。**前提**：先按第 3 步剔掉方差翻转的判定，否则评的是题面、不是复核员。
