## 维护纪律

- **一进一出**：新增门禁机制必须同时在本表登记，并点名它替代/合并的既有机制（无替代则说明增量理由）。
- **月度对账**：每月初按「触发统计口径」列刷新计数（半自动：`node <插件根>/scripts/agg-delegations.mjs` + `agg-judgments.mjs` 查判定流水 `.agents/judgments.jsonl`——check-loop 每次真实运行自动落账，2026-10-11 judgment-ledger 起替代人工 grep 输出；git log 统计口径不变）；
  达到阈值的行改「待退役」并填处置期限。
- **数据面机制的「现役」≠「有数据」**：复核效果台账与评审黄金集校准属数据面机制——黄金集 2026-10-21 已首跑（命中 24 / 误报 0 / 漏报 1，见该行），复核效果台账仍零跑数。月度对账时须区分两件事：① 资产是否存在；② 本月是否产生数据并写进留痕面（未产生 → 该月记「无跑数」，连续 6 个有数据月零记录才走退役阈值，**年轻遥测不得制造假候选**，口径同 `agg-judgments --retire-candidates`）。黄金集盲评动作与双臂/方差复跑口径见 `.agents/skills/review-method/golden-set.md` 使用方法节。
- **退役动作**：当日删除机制代码 + 其测试 + 本表该行，同一提交完成（不留死代码、不留已退役行，历史查 git）。
- **体量双闸（2026-10-23）**：① 总量受 `rule-budgets.txt` 预算行约束（超限 pre-commit 硬拦）；② 单行 > 800B 由检查 22 WARN——「最近触发」只留「建门 → 关键降档 → 当前态」，细节留 git 史。
- **健康静默型不适用零命中退役**：状态列标 `[健康静默]` 的机制（如 §4 引用有效性、§5 宿主 Adapter/命令指针壳/opencode 权限镜像、§19 逐阶段审计、§21 spec 验证落地、§22 台账格式、§26 漏斗阈值等），其「0 命中」语义为「当前无问题」而非「机制失效」，**不适用**「连续 6 月 = 0 → 评估退役」判据；月度对账时仅记「无跑数」，不产生退役候选。此类机制的退役须由「覆盖面失效」或「被替代机制取代」触发，由 owner 裁决后走「退役动作」同一提交删码 + 表更新。
- **模型代际触发（2026-10-16，deep-research 建议2）**：每个机制都是对当前模型能力边界的假设（外部实证：harness 组件随模型代际逐件移动），既有退役阈值只有使用维度、缺代际维度——主力模型**代际变更**（主版本号或模型家族更换，如 GLM-4.x → 5.x；小版本/推理档变更不算）后的**下一次月度对账**须按下面分组逐件重评去留，结论写各机制「最近触发」列；重评本身不改状态列（退役仍走既有阈值）。现役机制按能力假设分五组（本节用列表不用表格：检查 22 扫全文件 `|` 行，管道表会被误当机制行）：
  - **A · 纪律假设**（假设：无机器检查时模型会跳步/声称未做之事）——三件套同名配对、模板占位符残留、incident 复盘三件套、incident 归因字段、approved 留痕、确认指纹配对、逐阶段审计、spec 验证落地、闭环漏斗协议前动作阈值、委派台账对账、产品契约面归因、incident 防复发证据门。重评动作：观察新代际下 WARN/hard 是否加速归零（是 → 按既有退役阈值自然走）；**不因代际主动拆门**——判据已机器化、边际成本 ≈ 0，拆门收益低于一次漏拦。
  - **B · 能力边界假设**（假设：机制强度绑在当前模型能力短板上，代际升级后假设可能失效，**须主动重评**）——常驻面体积预算（注意力预算/context rot：长上下文能力增强 → 只重定上限不拆门，「臃肿被忽略」口径仍在）；独立复核上下文标识（跨会话上下文污染风险）；路由预判一致性 + 触达面判低门（判低逃逸倾向：观察新代际判低命中率，连续零命中走既有阈值）。其中证据真相核验 + 密钥扫描属信任边界/安全主干：**代际不撤门**，只重评执行成本。
  - **C · 机器判据**（纯确定性检查，与模型能力无关，代际免评）——引用有效性、判据级收敛对账、级别 vs 迁移 SQL 判低、frontmatter 模块词表、指标签名对账、文件名 kebab-case、状态严格枚举。
  - **D · 宿主生态**（跟宿主软件版本走，不跟模型代际；宿主升级时随 Adapter 检查顺带过）——宿主 Adapter 一致性、命令指针壳、opencode 权限镜像。
  - **E · 测量自举**（数据面，代际只影响测量结论的解释，不改机制本身；测量结论标注代际见 delegations.md 口径注「模型代际基线」）——门禁耗时埋点、机制退役催办、papercut 回路定时报债、复核效果台账。
