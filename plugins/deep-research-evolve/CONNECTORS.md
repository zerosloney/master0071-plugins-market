# 连接器

## 能力层级

**独立能力**（无连接器也完全可用）：
- 深度研究全流程（拆题/检索/交叉验证/引用报告）——走内置 WebSearch/WebFetch
- research/ 档案库、增量复研、对比评估打分、单文件 HTML 可视化报告

**增强能力**（连接后增强）：
- browser-use → 抓取 SPA、需登录态或正文渲染后才完整的目标页面（只读操作）
- repowiki（knowledge-center）→ 在代码仓库内调研时优先复用项目知识卡片，减少公网重复检索
- 宿主定时任务（cron）→ evolve `schedule` 创建周期自动复研任务

## 连接器清单

| 连接器 | 增强能力 | 缺失时降级 |
|--------|---------|-----------|
| **browser-use** | 动态/登录后页面取证 | 仅静态可取页面，冲突项标注"无法验证渲染态" |
| **repowiki** | 仓库内既有结论复用 | 直接读 `wiki/` 与源码 |
| **宿主 cron** | 定时自动重访 | INDEX.md 写"建议下次复研"日期，人工触发 |

> 本插件不自带 MCP server 声明（无 `mcp.json`），只按名引用宿主已连接的服务器，避免重复注册。
