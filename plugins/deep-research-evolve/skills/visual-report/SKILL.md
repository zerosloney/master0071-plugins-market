# Visual Report 可视化研究报告

## Overview

从既有调研材料生成一个可直接分发、离线打开的单文件 HTML，输出到 `research/<slug>/report-YYYYMMDD.html` 并在 log 记 `action:"report"`。

## 流程

1. **取材**：读 `research/<slug>/` 最新一期 report-*.md 与 notes.md；无档案时先要求用户提供材料或先跑 deep-research，不凭空造数。
2. **结构化**：提炼为固定信息架构——标题区（主题/日期/状态/总体置信度）→ 结论摘要卡片区 → 子问题发现（分节）→ 图表区 → 冲突与未决 → 来源清单。
3. **选图**（有量化/对比数据才画，宁缺毋滥）：
   - 多对象多维度打分 → 雷达图（配合 benchmark 产出）
   - 单维度数值对比 → 柱状图
   - 结论随时间演变（revisit 历史）→ 时间线
   - 机制/流程说明 → 简单流程框图
   - 无数据支撑的定性结论 → 用带置信度色标的卡片，不硬凑图表
4. **渲染**：以本技能 `assets/report-skeleton.html` 为基座填充内容（占位符 `{{...}}`），图表用内联 SVG 手工生成坐标，不引任何外部 CDN/字体/JS 库。
5. **交付**：写入文件后向用户报告路径；若宿主支持交互预览（如 canvas/浏览器打开），可建议用户本地打开查看。

## 质量门（生成后自查）

- [ ] 单文件离线可开：全文无 `http://`/`https://` 资源引用（来源清单里的 `<a href>` 正文链接除外）
- [ ] 每个结论卡片保留 `[n]` 角标且锚链接跳到来源区；来源含 URL 与访问日期
- [ ] 置信度视觉编码统一：高=绿 / 中=琥珀 / 低=红（沿用骨架 CSS 变量）
- [ ] 暗亮主题切换按钮工作正常（骨架自带，勿删其 script）
- [ ] 图表有 `<title>`/aria-label 说明，数据与 markdown 报告一致，不新增报告中没有的数字

## 硬约束

- 可视化只呈现既有结论，禁止在渲染阶段引入新论断或修改置信度。
- 图表数值必须能追溯到 markdown 报告原文；原文没有量化数据时只允许定性呈现。
