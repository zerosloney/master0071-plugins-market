## 本移植所做的修改

1. 位置改写：上游仓库的 `.claude-plugin/plugin.json`（Claude 专用清单）→ 本目录根 `plugin.json`（Agent Plugins 标准清单，封闭 schema）；上游仓库根的 `.claude-plugin/marketplace.json` → 本仓库根 `marketplace.json`。
2. 剔除：`.claude-plugin/icon.png`、`assets/`（约 1.9 MB 图片）、`pi/`（Pi 扩展，`skills/poteto-mode/references/pi-tools.md` 映射文档一并剔除）、`skills/poteto-mode/references/licenses/`（上游 skills-only 分发用的许可证副本，与本目录根三份 LICENSE 重复）、`.github/`（上游 CI 配置）、`tools/`（上游生成脚本；skill 内对该脚本的引用已改为「编辑 `models.json` 后手工同步各 Models 列表」，本移植不附带生成脚本）。`skills/poteto-mode/references/agents/comment-sicko.md` 与 `agents/comment-sicko.md` 双份保留是有意拷贝（codex-tools.md 引用前者）。
3. 新增（非上游原文，属本移植的打包层）：`.codex-plugin/plugin.json`——上游那份 `.codex-plugin/` 已随第 2 条剔除，本仓库按 Codex 插件 schema 重写了一份，只声明 `skills`、`SessionStart` hook 与 `interface` 展示信息，不含上游的 `prompts/` 命令垫片。
4. 改写 hook 执行层（非上游原文）：上游的 `session-start.sh` / `pre-tool-use.sh` / `session-start.ps1` 及其 awk 引擎在 Windows 宿主上经 shell 执行 `.sh` 会被按文件关联"打开"而非运行，故本移植将其全部移植为 node 脚本——`hooks/session-start.mjs`（统一 SessionStart 入口：宿主自检——检测到 `ZCODE_PLUGIN_ROOT`，或插件根路径含 `.zcode` 目录段（大小写不敏感、按段精确比对，`ZCODE_HOME` 可改模型表位置），即走 zcode 分支，否则按参数走 claude/codex/copilot；claude/codex 输出原文路由令，copilot 输出含角色行的 JSON，zcode 输出 `hookSpecificOutput.additionalContext` JSON）、`hooks/pre-tool-use.mjs`（Copilot PreToolUse 权限闸，含严格 JSON 解析与脚本契约；路径围栏用 `path.isAbsolute` 判定绝对路径并支持 Windows 盘符，`cwd` 全程显式传参，hook 输入缺 `cwd` 时向 stderr 记一行诊断后静默放行）、共享的 `hooks/sheet.mjs`（表解码与校验，移植 read-sheet.sh 与 sheet.awk）。两份被宿主实际接上的 hook 注册（`hooks/hooks.json` 与 `.codex-plugin` 内联）全部改为 node 调用；`hooks/copilot-hooks.json` 随包分发但**未被本仓库任何清单引用**，Copilot 宿主需按客户端自有约定手工登记（详见 `README.md` 的「已知缺口」段）；ZCode 实测按约定路径注册 `hooks/hooks.json`、不理会垫片 hooks 指针，靠脚本内自检切换分支。原 `.sh`/`.ps1`/`.awk` 共 7 个文件移入 `extras/upstream-reference/` 保留为上游参考（0.1.5 前位于 `hooks/upstream-reference/`），不再被任何注册引用；hook 依赖宿主机 Node ≥ 18。测试：`test/run-hook-tests.mjs`（hook 契约与表解码，含 resume/log/transcript 契约正反例）与 `test/sheet-parity.mjs`（awk↔mjs 一致性，无 awk 环境自动跳过）。另新增 `skills/poteto-mode/references/zcode-tools.md`（ZCode 工具与模型映射），setup-pstack 的运行时表补 ZCode 行，poteto-mode 的 Platform Adaptation 节补 ZCode 句。
5. 版本号独立：本插件以 `0.1.x` 发布，与上游 `0.9.86` / `0.15.x` 解耦；升级上游时对照上面的「源版本 / 源提交 / 内容同步」三行。
